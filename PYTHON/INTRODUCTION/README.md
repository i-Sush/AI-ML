# 🐍 Introduction to Python

## 1. What is Python?

Python is a **high-level, interpreted, general-purpose programming language**.

It is one of the easiest programming languages to learn because its syntax is simple and similar to the English language.

- **Created By:** Guido van Rossum
- **First Released:** 1991
- **File Extension:** `.py`
- **Programming Language:** Python

---

## 2. Features of Python

1. **Easy to Learn:** Python has simple and readable syntax.
2. **Interpreted Language:** Python code is executed by an interpreter.
3. **High-Level Language:** No need to manage low-level hardware operations.
4. **Open Source:** Python is free to download and use.
5. **Platform Independent:** Runs on Windows, Linux, and macOS.
6. **Object-Oriented:** Supports object-oriented programming.
7. **Large Libraries:** Provides many built-in modules and external libraries.

## 5. First Python Program

Let's write our first Python program.

### Code

```python
print("Hello World!")
```

### Output

```text
Hello World!
```

### Explanation

- `print()` is a built-in Python function.
- It is used to display output on the screen.
- `"Hello World!"` is the message we want to display.

---

## 6. How Python Works

The basic execution process:

1. Write Python code.
2. Save the file with the `.py` extension.
3. Run the Python program.
4. The Python interpreter executes the code.
5. The output is displayed.
